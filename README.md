# 🛍️ Apna Fashion — Achhe Kapde, Sahi Daam!

**Apna Fashion** is a modern, responsive clothing store website designed to showcase fashionable clothing for men, women, and children. The website focuses on stylish collections, budget-friendly shopping, seasonal clothing, and a welcoming experience for local customers.

🔗 **Live Website:** https://aman-tech-collab.github.io/Apna-Fashion/

---

## ✨ About the Project

Apna Fashion is a clothing shop located in Chhoti Ballia (Ballia Lakhminia), Begusarai, Bihar, India.

The website helps customers explore clothing collections, learn about the shop, contact the owner, and enjoy interactive games.

Our motto is:

> **Apna Fashion — Achhe Kapde, Sahi Daam!**  
> Har parivaar ki pasand, har budget ka khayal. ❤️

## 🚀 Features

- 📱 **Responsive Design** — Works on mobile, tablet, laptop, and desktop.
- 👕 **Multiple Clothing Collections** — Men's wear, women's wear, girls' wear, boys' wear, kids' clothing, and winter wear.
- ☀️ **Summer & Winter Fashion** — Clothing for different seasons and everyday use.
- 🖼️ **Fashion Gallery** — Attractive fashion images and collection cards.
- 👤 **Meet the Owner** — Introduction to Chikku Malakar.
- 🎯 **Style Finder** — Helps customers discover suitable clothing collections.
- 🎮 **Fashion Memory Match** — A clothing-themed matching game.
- 🧠 **Fashion Quiz Challenge** — Test your fashion knowledge.
- 🎡 **Spin the Fashion Wheel** — A fun, interactive fashion wheel.
- 💬 **WhatsApp Integration** — Contact the shop directly for product enquiries.
- 📞 **Call Now** — Contact the shop by phone.
- 📍 **Shop Location** — Address and Google Maps directions.
- 💸 **Budget-Friendly Shopping** — Highlights affordable clothing and available special offers.
- ✨ **Modern UI** — Stylish typography, elegant colors, and smooth interactions.

## 💻 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/AMAN-tech-collab/Apna-Fashion.git
```

### 2. Open the project folder

```bash
cd Apna-Fashion
```

### 3. Run the website

If the current version uses plain HTML, CSS, and JavaScript, open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for local development.

If the repository has been upgraded to React with Vite, follow the relevant `package.json` scripts and installation instructions instead.

## 🌐 Deployment

The website is hosted using GitHub Pages.

**Live URL:** https://aman-tech-collab.github.io/Apna-Fashion/

To publish updates:
1. Make your changes locally.
2. Commit and push the changes to GitHub.
3. Ensure GitHub Pages is configured for the correct repository branch or deployment workflow.
4. Open the live URL and verify the updated website.
